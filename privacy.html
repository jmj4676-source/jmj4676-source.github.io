개인정보처리방침

시행일 2026년 10월 6일

AIAI(이하 '이 프로그램')는 사용자 한 사람이 자기 PC에 설치해 쓰는 개인용 프로그램입니다. 이 문서는 이 프로그램이 Google 사용자 데이터를 어떻게 읽고, 쓰고, 보관하고, 전달하는지 설명합니다.

요청하는 Google 권한과 쓰는 목적

권한쓰는 목적
드라이브 읽기
drive.readonly		사용자가 질문할 때 관련 파일을 찾아 읽고 답에 참고합니다. 드라이브 파일을 고치거나 지우지 않습니다.
Gmail 읽기
gmail.readonly		사용자가 요청할 때 메일을 찾아 읽고 요약하거나 답에 참고합니다.
Gmail 보내기
gmail.send		사용자가 화면의 승인 카드에서 승인한 메일만 보냅니다.
캘린더 일정
calendar.events, calendar.calendarlist.readonly		일정을 읽어 알려 주고, 사용자가 승인한 일정만 등록하거나 고칩니다.
스프레드시트
spreadsheets		시트를 읽어 답에 참고하고, 사용자가 승인한 경우에만 내용을 씁니다.

보관

  • 로그인 정보(토큰)와 읽어 온 내용은 사용자 PC 안의 AIAI 데이터 폴더에만 저장됩니다. 개발자가 운영하는 서버는 없으며, 개발자가 이 데이터를 받지 않습니다.
  • 사용자는 언제든 AIAI 설정에서 Google 연결을 끊고, AIAI 데이터 폴더를 지워 저장된 내용을 없앨 수 있습니다.

다른 곳으로 전달

  • 사용자가 질문하면, 답을 만드는 데 필요한 범위의 내용만 사용자가 직접 로그인한 AI 서비스(OpenAI ChatGPT 또는 Anthropic Claude)로 보내집니다. 사용자가 원하는 기능을 제공하기 위한 전달이며, 그 밖의 목적으로 전달하지 않습니다.
  • 이 프로그램은 사용자가 각 AI 서비스에서 '모델 개선(학습)에 사용'을 끈 것을 확인한 뒤에만 그 계정을 씁니다.
  • Google 사용자 데이터를 판매하거나, 광고에 쓰거나, 사람이 따로 열람하지 않습니다. 범용 AI 모델을 만들거나 학습시키는 데 쓰지 않습니다.

Google API 서비스 사용자 데이터 정책 준수

AIAI가 Google API로 받은 정보를 쓰고 다른 앱으로 전달하는 방식은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

권한 철회

AIAI 설정 › 연결 앱 › Google의 [연결 해제], 또는 Google 계정 › 서드 파티 연결에서 언제든 권한을 없앨 수 있습니다.

Privacy Policy (English summary)

AIAI is a personal app installed and run by a single user on their own PC. It requests drive.readonly, gmail.readonly, gmail.send, calendar.events, calendar.calendarlist.readonly and spreadsheets to read the user's own data when the user asks, and to send email or change events and sheets only after the user approves each action. OAuth tokens and retrieved content are stored only on the user's PC; the developer runs no server and receives no data. To answer a request, only the necessary content is sent to the AI service the user signed into (OpenAI ChatGPT or Anthropic Claude), with model training turned off by the user. Google user data is never sold, used for advertising, read by humans, or used to develop or train generalized AI models.

AIAI's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Users can revoke access at any time in AIAI settings or at myaccount.google.com/permissions. Contact: 여기에-연락-이메일
