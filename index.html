AIAI

내 PC에서 실행하는 개인용 AI 비서입니다.

AIAI는 한 사람이 자기 컴퓨터에 설치해 쓰는 프로그램입니다. 사용자가 직접 로그인한 ChatGPT(OpenAI)·Claude(Anthropic) 구독 계정으로 질문에 답하고, 사용자가 연결을 허락한 경우에 한해 Google 드라이브·Gmail·캘린더·스프레드시트의 내용을 참고합니다. 별도 서버나 다른 사용자가 없으며, 판매하거나 공개 배포하는 서비스가 아닙니다.

Google 계정으로 하는 일

  • 사용자가 물을 때 드라이브 파일과 메일을 찾아 읽고 답에 참고합니다.
  • 일정을 읽고, 사용자가 화면의 승인 버튼을 누른 일정만 등록하거나 고칩니다.
  • 사용자가 승인한 메일만 보내고, 승인한 경우에만 스프레드시트에 씁니다.

자세한 내용은 개인정보처리방침과 이용약관에 있습니다.

About AIAI

AIAI is a personal AI assistant that a single user installs and runs on their own Windows PC. With the user's permission it reads the user's own Google Drive files, Gmail, Calendar and Sheets to answer the user's questions, and it sends email or changes calendar events and sheets only after the user approves each action on screen. There is no server operated by the developer and the app is not offered to the public. See the Privacy Policy and Terms of Service.
